# Aurora Artistry - Professional Makeup Artist Studio

Website portofolio dan pemesanan layanan makeup artist untuk **Aurora Artistry**, spesialis layanan Wedding, Lamaran, Wisuda, Party, dan Bridesmaids.

## 🚀 Fitur Utama
- **Hero & Profil Studio**: Tampilan visual bertema aurora borealis dengan logo khas.
- **Katalog Portofolio**: Galeri riasan interaktif dengan dukungan *Lightbox fullscreen viewer*.
- **Pricelist & Paket Layanan**: Informasi harga dan deskripsi paket.
- **Formulir Pemesanan WhatsApp**: Formulir booking instan yang otomatis terhubung ke WhatsApp admin.
- **FAQ Interaktif**: Pertanyaan yang sering diajukan dengan tampilan akordeon.
- **Modal Berbagi Sosial Media**: Fitur salin tautan dan share cepat ke WhatsApp, Facebook, dan X.
- **Desain Responsif**: Tampilan mobile-first yang elegan dan modern.

## 🛠️ Teknologi yang Digunakan
- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/)

## 💻 Cara Menjalankan Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/solusilokal/Aurora-Artistry.git
   cd Aurora-Artistry
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Build untuk production:**
   ```bash
   npm run build
   ```
